# Security Policy

## Supported versions

Pocket has no releases yet. Only the `main` branch gets fixes.

## Reporting a vulnerability

The repository is private, and GitHub offers private vulnerability reporting
for public repositories only, so the Security tab has no report form. Do not
report a vulnerability in an issue or a pull request: everyone with access to
the repository sees those.

- Email the maintainer: bketelsen@gmail.com.

If a credential (for example a Pocket server token) may be exposed, say so in
the first line, and rotate it before you send the details.

If the repository becomes public, GitHub's private vulnerability reporting is
also available: open the Security tab and click **Report a vulnerability**.

Do not post credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit.
- The impact: what an attacker can do.
- The steps to reproduce it.
