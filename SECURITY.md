# Security Policy

## Supported versions

Pocket has no releases yet. Only the `main` branch gets fixes.

## Reporting a vulnerability

The repository is private, and GitHub offers private vulnerability reporting
for public repositories only. Report a vulnerability to the maintainer, Brian
Ketelsen ([bketelsen](https://github.com/bketelsen) on GitHub), directly, not
in an issue or a pull request: everyone with access to the repository sees
those.

If the repository becomes public, use GitHub's private vulnerability reporting
instead: open the Security tab and click **Report a vulnerability**.

Do not post credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit.
- The impact: what an attacker can do.
- The steps to reproduce it.
