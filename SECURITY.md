# Security Policy

## Supported versions

Pocket has no releases yet. Only the `main` branch gets fixes.

## Reporting a vulnerability

The repository is public. Do not report a vulnerability in an issue, a pull
request or a discussion: everyone sees those.

- Open the Security tab and click **Report a vulnerability** (GitHub's private
  vulnerability reporting).
- If the Security tab has no report form, email the maintainer:
  bketelsen@gmail.com.

If a credential (for example a Pocket server token) may be exposed, say so in
the first line, and rotate it before you send the details.

Do not post credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit.
- The impact: what an attacker can do.
- The steps to reproduce it.
